STAYVISION V1 - ETAPA 10 - CONCILIACAO DO PIX JA RECEBIDO

ERRO CORRIGIDO:
O botao antigo do pedido chamava POST /api/admin/verify-payment, bloqueado pela mensagem de demonstracao. Agora o painel consulta a API de producao do Mercado Pago para CONCILIAR um pagamento existente.

NAO GERA NOVO LINK. NAO REALIZA PAGAMENTO. NAO AUTORIZA VENDAS PUBLICAS.

INSTALACAO:
1. Guarde o backup do volume /data, como ja realizado.
2. Extraia este ZIP e envie os arquivos na RAIZ do repositório GitHub StayVision, substituindo os anteriores, incluindo static/.
3. Espere a Railway mostrar Active. Nao remova o volume /data.
4. Mantenha STAYVISION_MP_CHECKOUT_MODE=restricted ou locked, e STAYVISION_MP_AUTO_CONFIRM=1 para conciliar o Pix ja recebido. NAO crie STAYVISION_MP_PUBLIC_LAUNCH.
5. Atualize o painel com Ctrl+F5, abra o pedido que recebeu o Pix e entre em "Conciliar pagamento real ja recebido".
6. Use o ID numerico da OPERACAO DE PAGAMENTO existente no Mercado Pago (nao o Pix, nem o Client ID); clique "Conferir e conciliar pagamento".
7. Se a API confirmar todos os dados, o campo "Status de pagamento" mudara para Pago. Se nao, a tela mostrara o motivo e NADA mudara.
8. Por fim, verifique Configurações > Notificacoes Mercado Pago e o status do webhook. A conciliacao manual repara este pedido, mas a entrega automatica do webhook ainda deve ser diagnosticada antes do lancamento.
