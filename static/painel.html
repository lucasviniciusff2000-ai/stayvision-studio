Pix de producao — diagnostico seguro

Consulte somente a lista de meios da sua conta real. O token deve ficar apenas nas variáveis privadas da Railway. O resultado informa se o Pix consta na API. Nao gera Pix, nao realiza cobrancas e nao ativa pagamentos reais.

Cadastre MP_PRODUCTION_ACCESS_TOKEN em Railway → Serviço → Variables, nunca no GitHub ou no navegador. O token não é exibido neste painel.

Esta versão online permite apenas pedidos demonstrativos quando autorizados. Pix de produção é CONSULTA SOMENTE: não ativa vendas, não cria cobranças e não altera o status de pagamentos.
