Publicação e cobranças

Verificando configuração...

Consulta segura à API do Mercado Pago. Não ativa Pix, não cria pagamento e não garante que ele apareça no Sandbox.

Pix de producao — diagnostico seguro

Consulte somente a lista de meios da sua conta real. O token deve ficar apenas nas variáveis privadas da Railway. O resultado informa se o Pix consta na API. Nao gera Pix, nao realiza cobrancas e nao ativa pagamentos reais.

Cadastre MP_PRODUCTION_ACCESS_TOKEN em Railway → Serviço → Variables, nunca no GitHub ou no navegador. O token não é exibido neste painel.

Notificações Mercado Pago — conferência somente leitura

Quando a notificação assinada chega, a StayVision consulta a API oficial do Mercado Pago por GET e registra o diagnóstico. Não cria cobranças, não aprova pedidos e não libera entregas.

Etapa 6 — Preparação de checkout real restrito

A conferência abaixo é uma prévia técnica, sem cobranças. Mesmo com a credencial de produção cadastrada, os pagamentos reais continuam bloqueados por padrão e não há vendas públicas.

Conferindo bloqueio de segurança...

A integração real só poderá ser liberada futuramente para um pedido especificamente autorizado. Não copie chaves para este campo.

Etapa 7 — Teste real RESTRITO (bloqueado por padrão)

Atenção: só após habilitação explícita pela Railway. Esta área pode gerar um link de pagamento real de R$ 49 para um único pedido Photo autorizado. Gerar o link não debita dinheiro; pagar por ele, sim. Não use dados de clientes reais nesta prova.

Verificando travas...

Somente o administrador pode obter esse link aqui. Não compartilhe até aprovar o teste.

Conferir pagamento pela API (somente leitura)

Depois de um teste autorizado, digite o código do pedido acima e o ID numérico do pagamento para consultar status, valor e vínculo diretamente no Mercado Pago, sem alterar pedidos.

Etapa 8 — Conferir proprietário do token (somente leitura)

Esta verificação consulta a identificação da conta associada ao Access Token de produção e compara com o ID de vendedor cadastrado. Não gera link, preferência, QR Code, Pix ou cobrança. Se houver divergência, nenhuma tentativa real poderá avançar.

Aguardando verificação. Checkout permanece bloqueado.

Para corrigir a variável da Railway, você pode consultar o ID numérico completo reconhecido pelo Access Token. O número é exibido somente neste painel após clicar; nunca exibe o token, e-mail ou senha. Confirme primeiro que a conta reconhecida é sua.

Na Railway, edite apenas o valor de MP_PRODUCTION_COLLECTOR_ID. Mantenha o nome da variável, token e checkout bloqueado.

Etapa 7: checkout restrito apenas mediante autorização escrita e configuração privada. O checkout público permanece BLOQUEADO por padrão. Não são aceitas vendas públicas e nenhum pagamento será criado sem autorização e configuração adicionais.
